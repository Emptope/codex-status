# Codex Status

一个小巧的跨平台 Codex 状态悬浮窗，采用极简、平面化界面，集中显示额度、会话活动及需要处理的状态。

当前已有 Rust + Tauri 2 + TypeScript + Svelte 5 原型，可在已配置工具链的开发环境运行。数据可行性和窗口原型仍有跨平台实测缺口，尚未进入正式发布阶段。
